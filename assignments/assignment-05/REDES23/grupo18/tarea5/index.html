¿Qué es el IMC?

El Índice de Masa Corporal (IMC) es una medida de asociación entre el peso y la talla de una persona. Es una herramienta útil para identificar posibles problemas de peso en adultos.

Rango IMC Clasificación
Menos de 18.5Bajo peso
18.5 - 24.9Peso Normal
25.0 - 29.9Sobrepeso
30.0 o másObesidad

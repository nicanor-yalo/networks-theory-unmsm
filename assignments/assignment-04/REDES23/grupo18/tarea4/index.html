Sobre las Herramientas de Despliegue

IONOS

Es el proveedor que nos brinda la infraestructura física. En otras palabras, es el servicio de hosting donde se alojan nuestros archivos y servidores para que la página web esté disponible en internet.

WinSCP

Es un programa gratuito para Windows que funciona como un puente de comunicación. Nos permite conectar nuestro ordenador personal con el servidor de IONOS de forma segura para transferir los archivos HTML, CSS e imágenes que conforman nuestra página web.
